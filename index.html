规则说明

        

          
游戏目标

          
捕捉宝可梦、获得分数和减免球。任意玩家达到 18 分后触发最终轮，最终分数最高者获胜。

        

        

          
每回合选择 1 个主要行动

          
    
            
  1. 拿 3 个不同普通球。若供应区只剩 2 种普通球可选，仍拿 3 个球，其中一种颜色拿 2 个，另一种颜色拿 1 个；不能拿大师球。
    2. 
            
  2. 拿 2 个相同普通球，但该颜色供应区拿取前至少有 4 个。
    3. 
            
  3. 保留一张 1/2/3 级卡，或从 1/2/3 级牌堆顶保留一张卡，并获得 1 个大师球。
    4. 
            
  4. 捕捉公共区或自己保留区中的一张宝可梦卡。
    5. 
          

        

        

          
捕捉与减免

          
捕捉需要支付卡牌上的费用。你已经捕捉的宝可梦会提供减免球，能永久抵扣对应颜色费用。大师球可以代替任意普通球。

        

        

          
进化规则

          
完成主要行动后，回合结束前可以进化 1 次。进化不消耗手里的 token，而是检查你面前已经捕捉宝可梦提供的减免球。旧卡进入进化记录，不再提供分数和减免。

        

        

          
token 上限

          
回合结束时最多保留 10 个 token，包括大师球。超过时必须丢弃到 10 个以内。

        

        

          
高亮说明

          
    
            
  • 绿色边框：当前可以捕捉。
    • 
            
  • 灰色半透明：当前暂时买不起。
    • 
            
  • 金色边框：当前可作为进化目标。
    • 
            
  • 紫色边框：当前可作为进化基础。
    • 
            
  • 蓝绿色边框：当前选中的卡。
    • 
          

        

        

          
球颜色对应

          
    
            
  • 红色：精灵球
    • 
            
  • 蓝色：超级球
    • 
            
  • 黑色：高级球
    • 
            
  • 粉色：治愈球
    • 
            
  • 黄色：先机球 / 速度球
    • 
            
  • 紫色：大师球
    • 
          

        

        

          
平局规则

          
若分数相同，进化记录更多者获胜；若仍相同，正面宝可梦数量更多者获胜。

        

      

    

  


  
  

    

    

      
      

        
如何联机？（局域网）

        
这只是局域网联机。如果朋友不在同一个网络，需要后续做公网部署。

        
    
          
  1. 房主电脑运行 npm start；
    2. 
          
  2. 房主打开 http://localhost:3000；
    3. 
          
  3. 创建房间；
    4. 
          
  4. 把加入链接发给朋友；
    5. 
          
  5. 朋友手机/电脑必须和房主在同一个 WiFi；
    6. 
          
  6. 如果打不开，请检查 Windows 防火墙是否允许 Node.js 访问网络；
    7. 
          
  7. 朋友进入后输入名字并加入房间；
    8. 
          
  8. 房主点击开始游戏。
    9. 
        

        
房间号可在房主界面点击「复制房间号」复制，加入链接可点击「复制加入链接」复制后发给朋友。
